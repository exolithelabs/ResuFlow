    Default template

    Instructions

    Rules for your agent, one per card. It reads them and can't change them.

      Examples: "Keep every resume to one page." · "Never mention my current employer by name." · "Use British spelling."

      Skills

      Writing playbooks built into ResuFlow. Connected agents load them on demand.

      Built in · read-only

      Connect an agent

      Your agent starts ResuFlow as a local subprocess over MCP. No server, port or account.

      MCP config

      Add this to your agent's MCP configuration. Any agent that supports MCP can use it.

      
            
      
            
      
              
      What your agent can do
      
              
        
                
      • Read your default template, instructions and every resume.
        • 
                
      • Create, tailor and edit resumes. You see the changes here as they happen.
        • 
                
      • Save the job posting a resume targets and check keyword coverage.
        • 
                
      • Archive and restore resumes. Only you can delete one.
        • 
                
      • Load the built-in skills for research, bullets, ATS passes and reviews.
        • 
              
      
              
      It can't change your instructions. If you and the agent edit the same resume at once, ResuFlow asks before anything is overwritten.
